# Removed prototypes

## Standalone radar and field-check page

Removed from the active build on 2026-11-15 because the map did not link to it
and the judged journey did not use it. The experiment included synchronized L/S
map controls and a session-only form comparing an entered root-zone measurement
with an entered crop/soil trigger. It never derived an irrigation instruction
from satellite values.

The related California 2008 public S-band sample was also removed from the
artifact. It demonstrated metadata extraction but was not co-located or
time-matched with the 2026 Nagapattinam observations, so it could not support
fusion or a field decision.

Work worth mentioning: the experiment helped define strict same-area,
compatible-time, grid, polarization, mask, and processing checks now retained
in the radar schema/exporter. The active map keeps a plain-language L/S status
and truthfully says matching evidence is unavailable.
